# Start here, Claude

Read `AGENTS.md`, then `docs/PLAYBOOK.md` and `docs/PROJECT.md`.
They define both the engineering workflow and how to guide a non-technical owner.
Read the stage-specific setup, deployment, and maintenance guides when needed.

Do not assume that a pasted repository link gives you local tools. Explain how to
continue in local Claude Code using `docs/SETUP.md` if this conversation cannot edit
files or run the site. Never claim you ran something you only described.

The owner reviews a **local** preview. Publication happens only with explicit
approval, through a direct push to the owner's `main` branch and GitHub Actions.
Do not introduce a pull-request workflow.
